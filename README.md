# Printable Lamp Lexicon

A moonlit magical-girl-styled cheat sheet of prompt vocabulary for designing 3D-printed lamps: lamp forms, shade silhouettes, surface patterns, 15 diagrammed mount types, socket and print terms, plus a prompt builder. Every term has a drawn preview, and the builder shows a live preview of the lamp you assemble.

Static site: `index.html`, `style.css`, `previews.js` (SVG preview renderer), `sparkle.js`. Hosted with GitHub Pages from the `main` branch root.
